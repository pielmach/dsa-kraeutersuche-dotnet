Einsteins DSA Tool
---------------------------

Installation
------------

Die setup.exe prüft das Vorhandensein von Abhängigkeiten, d.h. die .NET 10.0 Desktop Runtime (x64), und intalliert diese ggf. automatisch um anschließend das Tool selbst (EinsteinsDSATool-Setup.msi) zu installieren. Vorherige Versionen des Tools solltenn zuvor manuell deinstalliert werden.
